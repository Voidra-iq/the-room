# Glossary

Game terms, A to Z.

| Term | Meaning |
|---|---|
| Ability | Your character's special move on a cooldown. See [Abilities](abilities.md) |
| Bounty | Your current kill streak. Killing you is worth 1 + your bounty. See [Bounty](match-rules.md#bounty) |
| Cooldown | The wait before an ability can be used again |
| Execute | A heavy attack from behind: an instant kill. See [Execute](combat.md#execute) |
| Golden Knife | A pickup in the plaza: one-hit kills and double points for 20 s. See [The Golden Knife](match-rules.md#the-golden-knife) |
| Heavy | The slow, lunging attack. See [Heavy attack](combat.md#heavy-attack) |
| Last Call | The final stretch of a match: faster respawns, red clock. See [Last Call](match-rules.md#last-call) |
| Light | The quick stab. See [Light attack](combat.md#light-attack) |
| MVP | The winner of the match, on the gold step of the podium |
| Recovery | The moment after an attack when you can't act. The heavy's is long |
| Roll | The dodge: attacks pass through you while you roll. See [The roll](combat.md#the-roll-dodge) |
| Spawn protection | 1.5 s of safety after respawning. See [Dying and respawning](combat.md#dying-and-respawning) |
| Stagger | A short stun from a heavy attack or a Drop Kick |
| Stamina | The green bar: spent by sprinting and rolling |
| Tell | The visible wind-up before an ability, so it can be answered |
| Vault | Jumping over waist-high cover while running at it. See [Sprint, jump and stamina](combat.md#sprint-jump-and-stamina) |
| Whiff | An attack that misses |
